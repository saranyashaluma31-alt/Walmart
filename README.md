# Walmart Sales Analysis

## Project Overview
This project analyzes Walmart sales data using Python and Jupyter Notebook to identify sales patterns, customer trends, and business insights.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Sales Trend Analysis
- Product Performance Analysis
- Data Visualization

## Project Outcome
The project provides insights into Walmart sales performance and helps identify trends that support business decision-making.
